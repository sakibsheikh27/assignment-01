# DevConf — Developer Conference 2026

A responsive developer conference website built with HTML and CSS, featuring speakers, ticket pricing, and an event schedule.

## Features

* Navigation bar and hero section
* Speaker profile cards
* Conference ticket pricing plans
* Event schedule table
* Social media links and footer

## Technologies

* HTML5
* CSS3
* Font Awesome

## Getting Started

1. Clone the repository.
2. Open `index.html` in your browser.

```text
DevConf/
├── index.html

```
